# Улучшения StudentFlow: стабилизация и UX

- Исправлена работа сессий в iframe live preview: для preview включены Secure + SameSite=None; localhost остаётся на настройках разработки.
- После регистрации студент автоматически входит в систему; можно указать учебную группу.
- Добавлен `/account` для смены пароля; HMAC-штамп пароля аннулирует все старые сессии после смены пароля.
- Добавлены поиск пользователей в админ-панели и поиск/фильтр журнала преподавателя.
- Добавлены ограничение частоты входа, сравнение с dummy Argon2 hash для неизвестного пользователя и security headers.
- Брендированные страницы 404/500 и favicon; статические ресурсы используют same-origin URL.
- Добавлен `backup_db.py` с транзакционно согласованной SQLite-копией и проверкой целостности.
- Добавлены `.env.example`, dev-зависимости, CI workflow, реальные браузерные E2E-сценарии и расширенные регрессионные тесты.
- Добавлены транзакционные SQL-миграции с запуском при старте и общий SQLite rate limiter между процессами одного хоста.
- Добавлены удержание последних резервных копий и инструкции планировщика для cron/Windows Task Scheduler.
- Обновлён план улучшения `docs/IMPROVEMENT_PLAN.md`; миграции на PostgreSQL, Redis для нескольких хостов, автоматизированное удалённое хранилище backup и ручная браузерная проверка preview остаются будущими этапами.

## Проверка браузера и конфигурации безопасности

- Успешно выполнен Playwright E2E в Chromium, включая мобильный экран 390×844.
- Исправлены локаторы формы смены пароля и проверка фильтра журнала; оценка проверяется по `.score-badge`, а не по произвольному тексту страницы.
- Настраиваемый CSP `frame-ancestors`: безопасное значение по умолчанию в production и совместимость со встроенным development preview.
- Некорректный `--keep-days` отклоняется до создания резервной копии.
