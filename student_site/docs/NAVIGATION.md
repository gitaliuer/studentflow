# Карта навигации StudentFlow №9–10

Живая блок-схема доступна после входа: http://127.0.0.1:8000/lab10/map.

```text
[Главная /]
   ├─ нет сессии → [Вход GET /login]
   │                  ├─ ошибка POST /login → [Вход + сообщение]
   │                  └─ успешный POST /login → [/dashboard]
   └─ есть сессия ────────────────────────────→ [/dashboard]
                                                  │ роль
                 ┌────────────────────────────────┼─────────────────────────┐
                 ▼                                ▼                         ▼
        [Администратор /admin]          [Преподаватель /teacher]   [Студент /student]
           ↕ пользователи                    ↕ оценки                  ↕ раздел #grades
        /admin/users/{id}/edit           /teacher/grades/{id}/edit
           ↕ предметы
        /admin/subjects/{id}/edit

        Каждый кабинет и каждая страница редактирования имеют общее меню:
                 ┌─────────────────────────────────────────┐
                 ▼                                         ▼
       [Каталог + форма /lab10]  ←────────────────→ [План /lab10/plan]
                 │                                         │
           записать JSON                            прочитать JSON
                 ▼                                         ▲
                 └── [localStorage: studentflow.lab10.plan.v1] ─┘
                 │                                         │
                 └────────────→ [Карта /lab10/map] ←────────┘

        Любая защищённая страница → POST /logout → [Вход /login]
```

- Ссылки на редактирование ведут обратно в соответствующий кабинет.
- Якоря `#users`, `#subjects`, `#grade-form`, `#grade-list`, `#grades` переключают разделы той же страницы, это не самостоятельные страницы.
- Создание/обновление/удаление серверных данных идёт POST-запросами с CSRF и проверкой роли. Это действия, а не дополнительные страницы навигации.
- Страницы №10 доступны всем трём существующим ролям только после входа. Их GET-запросы не пишут в SQLite.
- `/static/*` — файлы оформления и JS; `/api/docs` — существующая техническая документация FastAPI, не часть учебного пользовательского маршрута.
- Неверная роль → 403; нет сессии → перенаправление на вход; отсутствующий объект редактирования → 404.

## Потоки данных

**Серверная часть №9:** браузерная форма → FastAPI (сессия, роль, CSRF, валидация) → SQLite → Jinja2 → HTML.

**Клиентская часть №10:** массив COURSES → DOM карточки → FormData → валидация → JSON.stringify → localStorage.setItem → переход на другую страницу → getItem → JSON.parse → валидация → DOM таблица.

LocalStorage не заменяет серверную защиту и не содержит копию таблиц users, students, subjects или grades.
