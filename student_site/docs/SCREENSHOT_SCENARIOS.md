# Скриншоты для лабораторной №10

Это **инструкция для реального запуска**, а не заявление о выполненных UI-проверках. В текущем комплекте изображения пока отсутствуют. Не подставляйте макеты вместо снимков работающего сайта.

## Подготовка

1. Запустите проект по README.md. Для первого запуска задайте пароли через set_passwords.py.
2. Откройте один и тот же адрес http://127.0.0.1:8000 во всех шагах. Не переключайтесь на localhost или другой порт.
3. Войдите под student1. Для демонстрации используйте учебные, а не личные данные. Не показывайте ввод пароля или DevTools со всеми cookies.
4. Откройте «Оқу жоспары · №10». Если план уже заполнен, сначала сохраните нужные вам сведения вручную. Кнопка «Оқу жоспарын тазарту» безвозвратно удаляет только этот учебный план и требует отдельного подтверждения.
5. Для снимков на компьютере удобно окно примерно 1440 × 1000. Если на странице видны реальные имя/группа, кадрируйте основной учебный модуль.

## 1. Карта переходов — 01_navigation.png

- Откройте «Сайт картасы», `/lab10/map`.
- Снимите блок-схему от главной страницы до ролевых кабинетов и новых страниц.
- Доказательство: видны пути /login, /dashboard, /admin, /teacher, /student, /lab10 и /lab10/plan, стрелки переходов.

Подпись: «1-сурет. StudentFlow беттерінің байланыс картасы».

## 2. JavaScript-каталог и форма — 02_form.png

- Откройте `/lab10`. Должны появиться 6 карточек; это результат массива COURSES.
- В карточке «JavaScript оқиғалары» нажмите «Таңдау».
- Установите 5 часов, приоритет «Жоғары».
- Убедитесь, что preview под формой показывает выбранный заголовок, 5 часов и приоритет.
- Нажмите «Жоспарға сақтау». Адрес останется /lab10, появится подтверждение сохранения.
- Снимите каталог, форму, preview и сообщение.

Подпись: «2-сурет. JavaScript формадан деректерді оқып, localStorage-қа сақтайды».

## 3. Чтение на другой странице — 03_saved_plan.png

- Нажмите «Сақталған жоспарды ашу →». Адрес должен измениться на /lab10/plan.
- Ожидается строка «JavaScript оқиғалары», 5 часов, «Жоғары»; показатели 1 / 5 / 1.
- Обновите страницу браузера. Данные должны остаться.
- Снимите таблицу и показатели. При необходимости включите в кадр адресную строку.

Подпись: «3-сурет. Басқа бетте localStorage деректері қайта оқылып, DOM кестесінде көрсетіледі».

## 4. Дополнительный сценарий — 04_updated_plan.png

- Вернитесь в редактор, выберите тот же JavaScript, поставьте 7 часов, «Қалыпты», сохраните дважды.
- На странице плана должна остаться одна строка, а не три; показатели 1 / 7 / 0.
- Добавьте «JSON және localStorage», 3 часа, «Жоғары».
- На странице плана ожидаются две строки и показатели 2 / 10 / 1.
- Этот снимок показывает динамическое изменение массива и суммы.

## 5. Ошибка формы и пустой список — дополнительно

- Попробуйте 0, 41, дробное число или пустые часы. Браузер не должен разрешать сохранение; прежний план не меняется.
- На странице плана нажмите «Оқу жоспарын тазарту», затем «Отмена»: строки сохраняются.
- Повторите и подтвердите: появляется «Жоспар әзірге бос». Остальные данные сайта не удаляются.

## 6. Повреждённое хранилище — только в тестовом профиле

При желании проверьте отдельно в DevTools → Application → Local Storage только ключ studentflow.lab10.plan.v1. Установите его значение в `{broken-json`, обновите страницу плана. Должно появиться сообщение об ошибке; ошибочный JSON не должен превращаться в пустой «успешный» план. Очистите только этот учебный ключ через кнопку модуля, подтвердив действие. Не изменяйте cookies, session или другие ключи.

## Мобильная проверка

В режиме устройства шириной 390 px проверьте все три страницы, откройте меню и перейдите на сохранённый план. Не должно быть горизонтального скролла всей страницы. Для широкой таблицы допустим локальный скролл её контейнера.
