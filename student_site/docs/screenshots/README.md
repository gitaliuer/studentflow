# Папка для реальных снимков

Скриншоты в этой папке пока не созданы: запуск Chromium в рабочей среде заблокирован ограничениями Unix-сокетов, а штатный расширенный запуск завершился инфраструктурной ошибкой.

Снимите работающий локальный сайт по ../SCREENSHOT_SCENARIOS.md и поместите сюда PNG. Не считайте этот README доказательством UI-проверки. Автоматический тест tests/check_lab10_browser.py из корня проекта при успешном запуске сохранит сюда снимки и отдельно отметит изолированный, не серверный режим проверки.
