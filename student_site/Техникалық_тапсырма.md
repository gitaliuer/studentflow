# Зертханалық жұмыс №9

**Тақырыбы:** Техникалық тапсырма және жүйеге қойылатын талаптар  
**Жоба атауы:** StudentFlow — студенттерді есепке алу ақпараттық жүйесі

## 1. Жүйенің мақсаты

StudentFlow — студенттер, оқу пәндері және бағалар туралы мәліметтерді бір жерде сақтауға және рөлдер бойынша өңдеуге арналған веб-жүйе. Мақсат — қағаз журналын немесе бөлек кестелерді пайдалануды азайту, оқу нәтижелерін қарауды жеңілдету және рұқсатсыз өзгерістердің алдын алу.

## 2. Негізгі пайдаланушылар және олардың рөлдері

| Пайдаланушы | Рөлі мен құқығы |
|---|---|
| Әкімші (admin) | Пайдаланушыларды тіркейді, өңдейді, рөлдерді тағайындайды, пәндерді қосады, оқытушыларды бекітеді. |
| Оқытушы (teacher) | Өзіне бекітілген пәндердің бағаларын енгізеді, өңдейді, қажет болса өшіреді. |
| Студент (student) | Тек өзінің тобын, пәндерін және бағаларын қарайды. Деректерді өзгерте алмайды. |

## 3. Функционалдық талаптар

| № | Талап | Орындау тәсілі |
|---|---|---|
| F1 | Пайдаланушы жүйеге логин және құпиясөз арқылы кіруі тиіс. | Авторизация беті, Argon2 хеші, сессия |
| F2 | Жүйе әкімші, оқытушы және студент рөлдерін ажыратуы тиіс. | Әр сұраныста рөлді тексеру |
| F3 | Әкімші пайдаланушыларды қосып, өзгертіп, жоя алуы тиіс. | Әкімші кабинетінің формалары |
| F4 | Әкімші пәндерді құрып, оқытушыға бекіте алуы тиіс. | `subjects` кестесі және басқару формалары |
| F5 | Оқытушы өз пәні бойынша студентке баға қоя алуы тиіс. | `grades` кестесіне жазу |
| F6 | Оқытушы тек өз пәнінің бағасын өзгерте және жоя алуы тиіс. | Сервердегі ownership тексеруі |
| F7 | Студент тек өзінің бағаларын көруі тиіс. | `student_id` бойынша сүзгі |
| F8 | Жүйе студенттің орташа балын есептеп көрсетуі тиіс. | Бағалардан орташа арифметикалық мән есептеу |
| F9 | Пайдаланушы жүйеден қауіпсіз шыға алуы тиіс. | Сессияны тазарту |

## 4. Функционалдық емес талаптар

| № | Талап | Шешім |
|---|---|---|
| NF1 | Қауіпсіздік: құпиясөз ашық күйде сақталмауы және рұқсатсыз әрекет жасалмауы керек. | Argon2, CSRF қорғанысы, рөлдік тексеру, параметрленген SQL |
| NF2 | Ыңғайлылық: интерфейс қазақ тілінде, түсінікті және телефонда қолдануға болатын болуы керек. | HTML/CSS, бейімделетін дизайн |
| NF3 | Деректер тұтастығы: бағалар нақты студент пен пәнге байланысуы керек. | SQLite foreign key және CHECK шектеулері |
| NF4 | Қолжетімділік: жүйе жергілікті компьютерде браузер арқылы ашылуы тиіс. | FastAPI + Uvicorn, `127.0.0.1:8000` |
| NF5 | Сүйемелдеу: код пен дерекқор жеке қабаттарда орналасуы тиіс. | HTML шаблондар, Python сервері, SQLite БҚ |

## 5. Кіріс және шығыс деректері

| Кіріс деректер | Шығыс деректер |
|---|---|
| Логин, құпиясөз | Кіру нәтижесі, пайдаланушы кабинеті |
| Пайдаланушының аты-жөні, рөлі, тобы | Пайдаланушылар тізімі |
| Пән атауы, оқытушы идентификаторы | Пәндер тізімі, жауапты оқытушы |
| Студент идентификаторы, пән, баға (0–100) | Бағалар журналы, студент нәтижелері, орташа балл |

## 6. Жүйенің негізгі функциялары

- Аккаунтқа кіру және шығу.
- Пайдаланушылар мен пәндерді басқару.
- Студенттерді оқу топтарымен байланыстыру.
- Бағаны енгізу, өзгерту, өшіру.
- Жеке нәтижелерді қарау және статистика шығару.

## 7. Архитектура және жобалау қабаттары

1. **Интерфейс қабаты:** HTML, CSS, JavaScript, Jinja2 шаблондары.
2. **Қолданба логикасы:** Python және FastAPI, рөлдер мен қауіпсіздік тексеруі.
3. **Деректер қабаты:** SQLite (`ак.db`), төрт байланысқан кесте.

**Кестелер және байланыстар:** `users.id` → `students.user_id`; `users.id` → `subjects.teacher_id`; `students.id` → `grades.student_id`; `subjects.id` → `grades.subject_id`.

## 8. Қысқаша техникалық тапсырма

**Жүйе атауы:** StudentFlow.  
**Орындау ортасы:** Windows компьютеріндегі жергілікті веб-сервер.  
**Технологиялар:** Python, FastAPI, SQLite, HTML/CSS/JavaScript.  
**Мәліметтер базасы:** `ак.db` (`users`, `students`, `subjects`, `grades`).  
**Міндетті нәтижелер:** пайдаланушыны тіркеу, рөлді тексеру, пәнді бекіту, баға қою, нәтижені қарау.  
**Қабылдау өлшемдері:** әкімші пайдаланушыны қоса алады; оқытушы өз пәнінен баға қоя алады; студент тек өз бағаларын көреді; рұқсатсыз әрекетке жүйе тыйым салады.

## 9. Шектеулер мен қолдану шарттары

- Жоба оқу мақсатына арналған, бастапқыда бір компьютерде жергілікті желісіз іске қосылады.
- Дерекқор файлы сервер жағында сақталады; оны браузерге тікелей беруге болмайды.
- Бағалар тек **0–100** аралығында енгізіледі.
- Пәнге оқытушы бекітілуі керек; оқытушы өзіне тиесілі емес пәннің бағасын өзгерте алмайды.
- Жүйе интернетке жарияланса, HTTPS, қосымша қауіпсіздік және резервтік көшіру қажет.

## 10. Нәтиже

Техникалық тапсырма, рөлдер сипаттамасы, функционалдық және функционалдық емес талаптар кестелері, кіріс және шығыс деректер тізімі дайындалды. Жүйенің жұмыс істейтін веб-нұсқасы мен SQLite базасы қоса беріледі.
